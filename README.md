# code-e-corte
Projeto Integrador de Modelagem de Dados: Code e Corte, aplicativo de agendamento para barbearias e salões de beleza. Reúne análise do negócio, requisitos, regras de negócio, fluxogramas, modelo conceitual (DER com 14 entidades), dicionário de dados e a evolução para o modelo relacional em SQL.
